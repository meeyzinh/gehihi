🚀 Máy chủ Xiaozhi Server (Tiếng Việt) đang hoạt động trực tuyến trên Render tại https://gehihi.onrender.com/

🤖 Bảng Điều Khiển Máy Chủ Xiaozhi ❤️

Hệ thống quản trị máy chủ thông minh cho Robot Xiaozhi (ESP32), hỗ trợ tương tác giọng nói hai chiều thời gian thực (Realtime Voice AI) bằng Tiếng Việt.

⚡ Hướng Dẫn Kết Nối Robot Xiaozhi ESP32 Vào Máy Chủ

  1. Đăng nhập Quản trị: Đăng nhập vào bảng điều khiển bằng tài khoản admin và mật khẩu ban đầu (hoặc mật khẩu tạm thời hiển thị trong nhật ký máy chủ).
  2. Cấu hình Nhà Cung Cấp (Provider): Vào mục Nhà cung cấp AI để cấu hình ít nhất 1 tổ hợp ASR (Nhận dạng giọng nói), LLM (Mô hình trí tuệ nhân tạo như OpenAI / Ollama / Doubao), và TTS (Giọng đọc EdgeTTS hoặc Doubao TTS).
  3. Cấu hình Robot kết nối đến Máy chủ:
    Khi Robot Xiaozhi ESP32 ở chế độ cấu hình mạng Wi-Fi (AP mode), hãy nhập đường dẫn OTA sau vào ô OTA URL:
    https://gehihi.onrender.com/api/ota/
  4. Nhận địa chỉ WebSocket tự động: Sau khi kết nối mạng thành công, Robot sẽ tự động gọi API OTA và nhận địa chỉ truyền dẫn WebSocket:
    wss://gehihi.onrender.com/ws
  5. Lấy mã kích hoạt & Ghép nối: Robot sẽ phát âm thanh đọc mã xác thực gồm 6 chữ số (hoặc hiển thị trên màn hình nếu có). Vào mục Trợ lý AI trên bảng điều khiển này, chọn Thêm thiết bị (hoặc liên kết mã), nhập địa chỉ MAC / mã xác thực để liên kết robot với trợ lý tương ứng.
  6. Trò chuyện: Khởi động lại hoặc bấm nút nói trên robot để bắt đầu đàm thoại mượt mà bằng tiếng Việt!
🎙️ Xử Lý Giọng Nói Thời Gian Thực
  • Hỗ trợ mã hóa âm thanh chất lượng cao OPUS và PCM
  • Đàm thoại 2 chiều Full-Duplex qua giao thức WebSocket bảo mật (WSS)
  • Hỗ trợ tự động ngắt lời (Barge-in / Voice Interruption) khi người dùng nói chen ngang
  • Tích hợp các mô hình giọng đọc TTS mượt mà (Microsoft EdgeTTS, Doubao, Deepgram...)
🧠 Trí Tuệ Nhân Tạo & MCP
  • Tương thích chuẩn OpenAI API (GPT-4o, Claude, DeepSeek, Qwen, Gemini...)
  • Hỗ trợ mô hình nội bộ không giới hạn qua Ollama
  • Hỗ trợ Model Context Protocol (MCP) trên cả server và client ESP32
  • Tự động thực thi công cụ: Xem giờ, thời tiết, phát nhạc, điều khiển nhà thông minh IoT
📱 Quản Trị Thiết Bị Linh Hoạt
  • Tự động cập nhật Firmware không dây qua OTA
  • Đồng bộ hóa múi giờ chuẩn Việt Nam (UTC+7)
  • Tạo nhiều nhân vật / trợ lý ảo khác nhau với Prompt và giọng đọc tùy biến
  • Hỗ trợ danh sách trắng (Whitelist MAC) để bảo mật chống truy cập trái phép
